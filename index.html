MySQL Database Tables Structure

Here is the exact schema and tables implemented as requested for this project:

Table 1: users
user_id INT PK AUTO_INCREMENT, full_name VARCHAR(100), email VARCHAR(100) UNIQUE, phone VARCHAR(20), role VARCHAR(20)

Table 2: movies
movie_id INT PK, title VARCHAR(150), genre VARCHAR(50), language VARCHAR(30), duration INT, release_data DATE

Table 3: shows
show_id INT PK, movie_id INT FK, theatre_name VARCHAR(100), show_data DATE, show_time TIME, ticket_price DECIMAL(10,2)

Table 4: bookings
booking_id INT PK, User_id INT FK, show_id INT FK, seats INT, total_amount DECIMAL(10,2), booking_status VARCHAR(30)

How to Import in MySQL Workbench:

  1. Open MySQL Workbench and connect to your local MySQL connection.
  2. Go to File > Open SQL Script...
  3. Select database/schema.sql and click Execute (Lightning Bolt icon).
  4. Next, open database/seed.sql and execute it to load sample movies and shows.
  5. Update your MySQL password in the .env file in VS Code.
